# 구매 플로우

## 0. 거래 기본 원칙

### 0-1. 상품 구매

사용자는 판매자와 1:1 문의를 하지 않아도 상품 상세 화면에서 바로 상품을 구매할 수 있다.

### 0-2. 1:1 문의와 결제 분리

사용자는 상품과 관련해 판매자에게 1:1 문의를 할 수 있다.

다만 1:1 문의는 상품 확인과 의사소통 목적으로만 제공하며, 채팅방 내에서는 결제를 지원하지 않는다. 채팅을 이용한 사용자도 상품 상세 화면으로 이동해 `바로 결제하기`를 선택해야 한다.

### 0-3. 직거래 미지원

키치캐치는 택배거래만 지원하며, 오프라인에서 만나 거래하는 직거래는 제공하지 않는다.

배송 추적과 구매 확정 여부를 확인할 수 있도록 판매자는 키치캐치가 지원하는 택배사와 유효한 운송장 번호를 사용해야 한다.

### 0-4. 안심결제 의무 적용

키치캐치에서 발생하는 모든 거래에는 안심 결제가 의무적으로 적용된다.

구매자가 결제한 금액은 키치캐치가 계약한 결제 대행사가 보관하고, 구매가 확정된 후 판매자에게 지급한다.

안심 결제는 별도의 결제수단이 아니므로 사용자가 적용 여부를 선택할 수 없다.

### 0-5. 본인 상품 구매 제한

판매자는 본인이 등록한 상품을 구매할 수 없다.

판매 중지, 삭제, 거래 제한 또는 다른 구매자가 결제를 진행 중인 상품은 구매할 수 없다.

---

## 1. 구매 진입

### 1-1. 바로 결제하기

구매자는 판매 중인 상품의 상세 화면에서 `바로 결제하기`를 선택할 수 있다.

### 1-2. 구매 가능 여부 확인

사용자가 `바로 결제하기`를 선택하면 시스템은 다음 사항을 확인한다.

- 상품이 판매 중인지 확인한다.
- 다른 구매자가 결제 중인지 확인한다.
- 판매자가 본인이 아닌지 확인한다.
- 이용 제한 또는 결제 제한 대상인지 확인한다.
- 배송 가능한 상품인지 확인한다.

구매할 수 없는 상태이면 결제 화면으로 이동하지 않고 사유를 안내한다.

---

## 2. 결제 화면

구매자는 결제 화면에서 다음 정보를 확인한다.

### 2-1. 상품 정보

- 상품 대표 사진.
- 상품 제목.
- 상품 가격.
- 배송비.
- 판매자 정보.
- 상품 상태.
- 배송 방법.

상품 대표 사진은 판매자가 등록한 첫 번째 사진을 사용한다.

### 2-2. 배송지 정보

구매자는 기본 배송지를 확인하거나 다른 배송지로 변경할 수 있다.

배송지에는 다음 정보가 포함된다.

- 수령인.
- 휴대전화번호.
- 우편번호.
- 기본 주소.
- 상세 주소.
- 배송 요청사항.

구매자의 배송지 정보는 결제가 완료된 후에만 판매자에게 제공한다.

제주도와 도서산간 지역에 추가 배송비가 발생한다면 결제 전에 금액을 표시해야 한다.

### 2-3. 결제 방법

출시 초기에는 다음 결제수단을 제공한다.

- 신용·체크카드.
- 실시간 계좌이체.
- 가상계좌·무통장입금.

`가상계좌`와 `무통장입금`은 별도의 결제수단으로 나누지 않는다. 결제 화면에는 `가상계좌·무통장입금` 하나로 표시하고, 실제 처리는 주문별 PG 가상계좌를 발급하는 방식으로 진행한다.

**간편 결제와 휴대폰 결제는 토스페이먼츠로부터 C2C 판매자 지급대행과 구매 확정 전 대금 보관이 가능하다는 서면 확인을 받은 후 추가한다.**

### 2-4. 안심 결제 이용료

안심 결제 이용료는 다음 기준으로 계산한다.

```
안심 결제 이용료
= 상품 금액과 배송비 합계의 5.5%
= 계산 결과가 800원보다 적으면 800원 적용
```

계산 결과는 원 단위로 반올림한다.

이용료는 구매자가 부담하고 판매자에게는 별도의 판매 수수료를 부과하지 않는다.

### 2-5. 최종 결제금액

결제 화면에는 다음 금액을 구분해 표시한다.

| 항목 | 설명 |
| --- | --- |
| 상품금액 | 판매자가 등록한 상품 가격 |
| 배송비 | 판매자가 설정한 배송비 |
| 안심결제 이용료 | 상품금액과 배송비 합계의 5.5%, 최소 800원 |
| 최종 결제금액 | 상품금액 + 배송비 + 안심결제 이용료 |

예시는 다음과 같다.

| 항목 | 금액 |
| --- | --- |
| 상품금액 | 50,000원 |
| 배송비 | 3,000원 |
| 안심결제 이용료 | 2,915원 |
| 최종 결제금액 | 55,915원 |

### 2-6. 필수 동의

구매자는 결제 전에 다음 사항을 확인하고 동의해야 한다.

- 주문 상품 및 결제금액 확인.
- 배송지 정보 제공 동의.
- 안심결제 이용료 확인.
- 취소·반품·환불 정책 확인.
- 개인정보 제3자 제공 동의.
- 구매 조건 및 서비스 이용약관 동의.

## 3. 상품 선점 및 중복 결제 방지

### 3-1. 결제 진행 중

카드 또는 계좌이체 결제를 시작하면 상품을 일정 시간 동안 `결제 진행 중` 상태로 전환한다.

결제 진행 제한시간은 10분으로 설정한다.

해당 시간 동안 다른 사용자는 결제를 시작할 수 없지만 상품 상세 정보는 조회할 수 있다.

### 3-2. 결제 실패

결제가 실패하거나 제한시간이 지나면 상품을 다시 `판매 중` 상태로 전환한다.

### 3-3. 결제 완료

결제가 성공하면 상품을 `거래 진행 중`으로 전환하고 다른 사용자의 구매를 차단한다.

동시에 여러 결제가 시도된 경우 결제 완료 처리가 가장 먼저 확정된 주문만 유효하게 처리한다.

---

## 4. 결제수단별 처리

### 4-1. 신용·체크카드

카드 승인이 완료되면 즉시 결제 완료로 처리한다.

카드 승인에 실패하면 주문을 생성하지 않거나 생성된 결제 대기 주문을 취소한다.

### 4-2. 실시간 계좌 이체

계좌 이체가 완료되면 즉시 결제 완료로 처리한다.

이체 실패 또는 사용자 중단 시 상품 선점을 해제한다.

### 4-3. 가상계좌·무통장입금

구매자가 가상 계좌를 선택하면 주문 전용 계좌를 발급한다.

- 입금 기한은 계좌 발급 시점부터 24시간이다.
- 입금 전 주문은 `입금 대기` 상태로 관리한다.
- 입금 대기 중에는 다른 사용자가 해당 상품을 구매할 수 없다.
- 구매자는 안내된 금액과 동일한 금액을 입금해야 한다.
- 정상 입금이 확인되면 결제 완료로 처리한다.
- 기한 내 입금되지 않으면 주문을 자동 취소한다.
- 자동 취소 후 상품을 다시 판매 중으로 전환한다.
- 취소된 가상계좌 주문은 복구하지 않는다.
- 기한이 지난 뒤 입금된 금액은 주문을 복구하지 않고 전액 환불한다.

한 사용자가 상품을 장시간 선점하는 것을 방지하기 위해 입금 대기 주문의 반복 생성은 제한할 수 있다.

---

## 5. 결제 완료

결제가 완료되면 구매자에게 다음 정보를 제공한다.

- 주문번호.
- 상품 정보.
- 결제수단.
- 결제금액.
- 배송지.
- 예상 발송기한.
- 주문 상태.
- 취소 및 문의 방법.

판매자에게는 신규 주문 알림을 발송하고 다음 정보를 제공한다.

- 주문번호.
- 판매 상품.
- 수령인과 배송지.
- 배송 요청사항.
- 발송기한.
- 운송장 등록 방법.
- 예상 정산금액.

안심 결제 이용료는 구매자가 부담하므로 판매자의 예상 정산 금액에는 영향을 주지 않는다.

---

## 6. 판매자 발송

### 6-1. 발송기한

판매자는 결제 완료일부터 3영업일 이내에 상품을 발송해야 한다.

### 6-2. 배송정보 등록

판매자는 다음 배송 정보를 등록해야 한다.

- 택배사.
- 운송장 번호.
- 발송일.

운송장 번호만 등록한 상태는 실제 발송으로 인정하지 않는다. 택배사에서 상품 집하가 확인된 시점을 발송 완료로 본다.

### 6-3. 발송 지연

판매자가 3영업일 이내에 발송하지 않으면 구매자는 주문을 취소할 수 있다.

결제 완료일부터 5영업일까지 발송하지 않으면 주문을 자동 취소하고 구매자에게 전액 환불한다.

### 6-4. 판매자 취소

품절, 상품 훼손 또는 판매 불가 등의 사유로 판매자가 주문을 취소하면 구매자에게 상품금액, 배송비 및 안심결제 이용료를 전액 환불한다.

반복적으로 주문을 취소하는 판매자는 판매 활동을 제한할 수 있다. (추후 논의 필요)

---

## 7. 배송 진행

배송 상태는 택배사 배송조회 정보와 연동한다.

```
배송 준비 → 집하 완료 → 배송 중 → 배송 완료
```

구매자는 주문 상세 화면에서 배송 상태와 운송장 번호를 확인할 수 있다.

배송 완료 여부는 택배사가 제공한 배송 완료 정보를 기준으로 한다.

---

## 8. 구매 확정

### 8-1. 직접 구매 확정

구매자는 상품을 수령하고 상태를 확인한 후 `구매 확정`을 선택할 수 있다.

구매 확정 전 다음 내용을 안내한다.

> 구매를 확정하면 판매자에게 정산이 진행되며, 단순 변심에 따른 취소가 제한됩니다. 상품 상태를 충분히 확인한 후 구매를 확정해 주세요.
> 

### 8-2. 자동 구매 확정

구매자가 직접 확정하지 않으면 배송완료 시점부터 7일 후 자동으로 구매 확정한다.

자동 구매 확정 전에 구매자에게 알림을 발송한다.

- 배송완료 알림.
- 자동 구매 확정 3일 전 알림.
- 자동 구매 확정 1일 전 알림.

### 8-3. 자동 확정 중지

다음 상황에서는 자동 구매 확정을 중지한다.

- 반품 요청이 접수된 경우.
- 환불 요청이 접수된 경우.
- 상품 관련 분쟁이 접수된 경우.
- 배송완료 여부가 확인되지 않는 경우.
- 배송사고가 접수된 경우.

---

## 9. 주문 취소

### 9-1. 발송 전 취소

택배사 집하 전까지 구매자는 주문을 즉시 취소할 수 있다.

판매자의 별도 승인은 필요하지 않다.

취소가 완료되면 상품금액, 배송비 및 안심결제 이용료를 전액 환불한다.

### 9-2. 발송 후 취소

택배사 집하 이후에는 주문 취소가 아닌 반품 절차를 적용한다.

### 9-3. 자동 취소

다음 상황에서는 주문을 자동 취소할 수 있다.

- 가상계좌 입금기한 초과.
- 판매자의 발송기한 초과.
- 결제 승인 실패.
- 중복 결제.
- 판매 금지 상품 확인.
- 결제도용 또는 부정거래 확인.
- 시스템상 복구할 수 없는 주문 오류.

---

## 10. 반품 및 환불

### 10-1. 반품 요청

구매자는 상품 수령일부터 7일 이내에 반품을 요청할 수 있다.

상품이 설명과 다르거나 미고지 하자, 위조품, 오배송 또는 구성품 누락에 해당하면 별도 분쟁 절차를 이용할 수 있다.

### 10-2. 배송비 부담

- 단순 변심에 따른 왕복 배송비는 구매자가 부담한다.
- 상품 하자, 오배송 또는 설명 불일치에 따른 배송비는 판매자가 부담한다.
- 택배사 책임으로 확인된 파손은 택배사 보상 절차를 진행한다.

### 10-3. 환불 처리

반품 상품 수령과 상태 확인이 완료되면 환불을 진행한다.

전체 환불 시 상품금액, 최초 배송비 및 안심결제 이용료의 환불 범위는 귀책사유에 따라 결정한다.

- 판매자 귀책이면 안심결제 이용료를 전액 환불한다.
- 결제 취소 또는 거래 무효이면 안심결제 이용료를 전액 환불한다.
- 부분 환불이면 환불 비율에 따라 안심결제 이용료도 부분 환불한다.

### 10-4. 구매 확정 후

구매 확정 이후에는 단순 변심에 따른 취소와 반품이 제한된다.

다만 위조품, 도난품, 미고지 하자, 고의적인 허위 설명 또는 거래금지 상품은 구매 확정 이후에도 신고할 수 있다.

---

## 11. 분쟁 처리

구매자가 분쟁을 접수하면 다음 처리를 즉시 적용한다.

- 자동 구매 확정을 중지한다.
- 판매자 정산을 중지한다.
- 상품과 주문 정보를 보존한다.
- 구매자와 판매자에게 증빙자료 제출을 요청한다.

제출 가능한 자료는 다음과 같다.

- 상품 사진과 영상.
- 포장 상태.
- 개봉 영상.
- 운송장과 배송정보.
- 상품 설명.
- 1:1 문의 내용.
- 결제 및 환불 기록.

분쟁이 해결될 때까지 결제 대금은 판매자에게 지급하지 않는다.

---

## 12. 판매자 정산

### 12-1. 정산 시작

구매자가 직접 구매를 확정하거나 자동 구매 확정이 완료되면 판매자 정산을 시작한다.

### 12-2. 정산금액

```
판매자 정산금액
= 상품금액 + 판매자에게 지급되는 배송비
```

안심결제 이용료는 구매자가 별도로 부담하므로 판매자 정산금액에서 차감하지 않는다.

### 12-3. 정산기한

구매 확정일부터 2영업일 이내에 판매자 본인 명의 계좌로 지급한다.

주말, 공휴일, 계좌 오류 또는 금융기관 점검시간에는 지급이 지연될 수 있다.

### 12-4. 정산 보류

다음 상황에서는 정산을 보류할 수 있다.

- 반품·환불 또는 분쟁 진행 중.
- 결제도용이나 사기 의심.
- 위조품 또는 금지상품 신고.
- 판매자 본인확인 미완료.
- 정산계좌 명의 불일치.
- 수사기관 또는 금융기관의 요청.

## 13. 주문 상태

권장 주문 상태는 다음과 같다.

```
판매 중
→ 결제 진행 중
→ 입금 대기
→ 결제 완료
→ 배송 준비
→ 배송 중
→ 배송 완료
→ 구매 확정
→ 정산 대기
→ 정산 완료
```

예외 상태는 별도로 관리한다.

```
결제 실패
주문 취소
자동 취소
반품 요청
반품 중
분쟁 중
환불 대기
환불 완료
정산 보류
```

## 최종 화면 구조

```
상품 상세
└─ 바로 결제하기
   └─ 주문·결제
      ├─ 상품 정보
      ├─ 배송지 정보
      ├─ 결제 방법
      │  ├─ 신용·체크카드
      │  ├─ 계좌이체
      │  └─ 가상계좌·무통장입금
      ├─ 안심결제 이용료 안내
      ├─ 최종 결제금액
      └─ 결제하기
```

안심 결제는 모든 결제수단에 공통으로 적용한다.

간편 결제와 휴대폰 결제는 승인되면 기존 결제 방법 목록에만 추가하면 됨.
